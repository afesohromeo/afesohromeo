## 👨‍💻 About Me

I'm a **Flutter developer** building mobile, web and full-stack Dart applications.

Over the past **4+ years**, I've designed and delivered production applications spanning **enterprise ERP**, **healthcare**, **transport management**, **geospatial services**, and **mobile payments**.

I care about how software is built as much as what it does: written engineering standards, test-first development (`bloc_test`, `mocktail`), and architectures a team can grow. I work with AI coding agents (Claude Code, MCP servers, agent skills) through a disciplined process: specs and plans approved before code, and every change verified by tests.

Lately I've been building full-stack in Dart with **Serverpod**, and publishing the standards I work by so other developers and their agents can use them.

## 🚀 Featured Projects

### 🏗️ [Plotwatch](https://plotwatch.serverpod.space) *(Serverpod hackathon, October 2026)*

Oversee a construction project from anywhere. Site managers capture **verified photos** (in-app camera only, GPS, server-side checks against the site boundary, time and SHA-256 hash), funders approve the build **stage by stage**, and a shared **ledger** tracks every release and expense with receipts. Live updates, English and French.

**Tech**

`Flutter` • `Serverpod 4` • `PostgreSQL` • `BLoC` • `GoRouter` • `Serverpod Cloud`

🌐 **Try the web app:** [plotwatch.serverpod.space](https://plotwatch.serverpod.space) • 💻 **Source:** [github.com/afesohromeo/plotwatch](https://github.com/afesohromeo/plotwatch)

### 🤖 [flutter-bloc-skills](https://github.com/afesohromeo/flutter-bloc-skills)

Agent skills for Flutter apps built with flutter_bloc (Claude Code, Codex, Cursor and others): a feature workflow that asks before it guesses, one error message per failure case, Serverpod 4, and code review against a team's rules. Each skill was **tested with and without it** on two projects; the results are published in the repo.

`npx skills add afesohromeo/flutter-bloc-skills`

---

### 🧱 [flutter_bloc_kit](https://github.com/afesohromeo/flutter_bloc_kit)

Production-ready Flutter starter kit: a layered architecture inspired by Clean Architecture, with UI and BLoCs organised by feature; BLoC + Freezed, GoRouter, Dio or Serverpod, English and French, responsive layouts and reusable components. Ships with **written engineering standards (51 rules)**, a reference feature, **136 tests**, a screenshot harness and an agent setup (`CLAUDE.md`).
